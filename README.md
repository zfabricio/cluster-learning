# Projeto Cluster-Learning 🚀

Este repositório demonstra como funciona o processamento paralelo usando **Node.js Cluster** e **GitHub Actions**.

## O que este projeto faz?
1.  **Simula um Cluster Local:** Usa o código em `app.ts` para dividir tarefas entre os núcleos do teu processador.
2.  **Usa o Cluster do GitHub:** Através do GitHub Actions, o código é testado num ambiente de nuvem.

## Como rodar localmente
1. Instale as dependências: `npm install ts-node typescript @types/node`
2. Execute o comando: `npx ts-node app.ts`# cluster-learning
